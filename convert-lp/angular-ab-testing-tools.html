Your dev team runs Angular experiments from inside the pipeline, not around it

Angular teams build and ship in code, not in marketing dashboards. Convert's REST API V2 lets your team create, update, and report on experiments entirely inside your CI/CD pipeline. JS Conditions let you write arbitrary JavaScript as a targeting trigger.

  • REST API V2 integrates into your Angular CI/CD pipeline directly
  • JS Conditions target on Angular router events, component state, or service values
  • Both features ship on standard plans, not behind an enterprise contract
angular-experiment.ts 
// Create experiment via REST API V2
import { ConvertClient } from '@convertcom/js-sdk';
import { Router, RouterEvent } from '@angular/router';

const client = new ConvertClient({
  sdkKey: process.env.CONVERT_SDK_KEY,
});

// JS Condition targeting Angular router events
const jsCondition = `
  router.events.pipe(
    filter(e => e instanceof RouterEvent),
    map(e => e.url)
  ).includes('/onboarding/step-2')
`;

// Create experiment with JS condition
await client.experiments.create({
  name: 'onboarding-step2-cta',
  targeting: { js_condition: jsCondition },
  variants: [
    { name: 'control' },
    { name: 'variant-a' }
  ],
});

FAQ

Common questions about Convert and Angular

01 Does Convert support Angular SPAs out of the box, or does it need custom configuration?

Convert supports Angular SPAs natively. The platform uses MutationObserver to detect DOM changes triggered by Angular's rendering cycle and client-side router, so there's no custom configuration required to handle route transitions. You install the Convert snippet, and it tracks Angular page changes the same way it would track a traditional full-page reload, without needing to hook into Angular's lifecycle events manually.

02 How does Convert prevent the flicker effect on Angular applications?

Convert loads synchronously via Akamai CDN, which means the snippet executes before Angular bootstraps and before the initial paint. This prevents the flicker-on-load problem where visitors briefly see the control variant before the test variant applies. For route changes within the Angular app, MutationObserver detects the DOM update and applies the experiment modification before the user sees the new view. The result is clean variant delivery with no flash of original content at any point in the session.

03 Can I use JS Conditions to target Angular component state or router events?

Yes. Convert's JS Conditions accept arbitrary JavaScript, so you can write targeting logic that references Angular's router, component state, or injected service values. You're not limited to URL matching or cookie values. A JS Condition can evaluate Angular router events, check a value exposed on the window object by your application, or run any other synchronous JavaScript check before deciding whether to include a visitor in an experiment. This feature is included on standard Convert plans and is not gated behind an enterprise tier.

04 Does the Convert JS SDK work with Angular's module system and tree-shaking?

Yes. The @convertcom/js-sdk package is distributed as an ES module and is compatible with Angular's build system and tree-shaking. For client-side use, you can import only the functions you need. For server-side or Node.js use within an Angular Universal (SSR) setup, the SDK exports a separate entry point designed for Node environments. Bundle size impact is minimal because unused SDK features are excluded from the production build automatically.

05 Can Convert run server-side experiments on the APIs powering an Angular app?

Yes. Convert supports full-stack and server-side experimentation. You can run experiments at the API layer, on recommendation logic, pricing calculations, or any backend service that Angular's frontend consumes. The server-side SDK integrates with Node.js backends and works alongside Angular Universal for SSR use cases. Experiment results from server-side and client-side tests appear in the same unified dashboard, so you're not managing separate reporting streams.

06 How does Convert handle experiment assignment for users navigating across multiple Angular routes?

Variant assignment is persistent across route changes within the same session. Convert sets a first-party cookie on the visitor's first exposure, and that assignment is honored for subsequent route changes within the Angular app. MutationObserver re-evaluates targeting conditions on each route change, but the variant assignment for a visitor already in an experiment remains stable. This prevents users from seeing different variants as they navigate between views in the app.

07 What stats models does Convert support, and do I need to upgrade to access Bayesian testing?

Convert includes Frequentist, Bayesian, and Sequential testing models on every plan. There is no upgrade required to access Bayesian or Sequential testing. Frequentist testing gives you p-values and confidence intervals, which most engineering teams prefer. Bayesian testing gives you probability-to-beat, which is more intuitive for business stakeholders. Sequential testing lets you evaluate results at any point during a running experiment without inflating false positive rates, which is useful for teams that can't wait for a fixed sample size before making decisions.

08 Can Convert integrate with the CI/CD pipeline we already use to ship our Angular app?

Yes. Convert's REST API V2 is designed for programmatic access from CI/CD environments. You can create experiments, update variants, manage goals, and pull reporting data entirely through the API without touching the Convert dashboard. The MCP server adds a layer of integration for AI-assisted development workflows, letting your team manage experiments directly from tools like Cursor or other MCP-compatible editors. Both the REST API and the MCP server are available on standard plans.

09 How does Convert handle data privacy for Angular apps in regulated industries?

Convert is ISO 27001 certified, SOC-2 compliant, HIPAA compliant, GDPR compliant, and CCPA compliant. It has had zero security breaches in its 16-year history. For regulated industries like healthcare, insurance, and mental health, Convert supports data processing agreements and offers configuration options to minimize PII collection. You can use Convert in HIPAA-covered environments. Experiment data is unsampled and stored without sharing with third-party advertising networks.

10 What does the onboarding process look like for an Angular team that's never used Convert before?

The 15-day free trial gives you full access to every feature from day one, including server-side testing, JS Conditions, and both stats engines. There's no feature gating during the trial. Most Angular teams have their first experiment running within a few days of signing up. Convert's support team is available throughout onboarding with an average first response time of 7 minutes, reached by a human engineer who can help with Angular-specific implementation questions. You can also access the SDK quickstart documentation, REST API reference, and MCP server setup guide without a sales call.

11 Can I build Angular variations visually, or do I have to write code?

Both. The Convert Visual Editor includes an SPA mode for Angular apps, so you can point and click to build variations on dynamically rendered views without writing code. Because Angular components can take a moment to render, the editor exposes a configurable load-wait so it pauses for the DOM to settle before loading elements, set to 8 seconds by default and adjustable to match your app. Developers who prefer code can skip the editor entirely and define variations through JS Conditions and the SDK.
